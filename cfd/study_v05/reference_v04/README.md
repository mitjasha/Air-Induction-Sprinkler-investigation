# v0.4 CFD numerical reference — OpenFOAM v2606

These are **user-exported numerical results from v0.4**, *not* experimental
measurements, not generated by the v0.5 turbulence model, and not a solver
validation dataset. Both ParaView Plot Over Line CSV files refer to 60 ms.

- `axis_profile_60ms.csv`: r=1.0 mm, user data only to z=45 mm (despite intended
  sample to 90 mm). Profile completeness warning is intentional.
- `wall_profile_60ms.csv`: r=4.5 mm, z=10–90 mm.
- The numerical output `summary.json` and plots were generated by v0.5
  `cfd.study_v05.analyze` using the user CSV and **one transcribed signed flux
  observation at 60 ms**, not the complete solver time history.
- Original signed wedge fluxes at 60 ms [m³/s]: waterInlet -8.158300457e-06,
  airInlet -2.076180457e-06, ambientOpen -2.075811882e-07,
  outlet +1.044205789e-05. Consequently `k_phi=0.25448688` (mixture ratio).
  This is not phase-specific entrained air and not a validated kQ.
- A sample pressure step or a smooth pressure recovery alone cannot establish
  or exclude a mixing shock; compare with 3D, RANS/laminar sensitivity and
  experimental evidence before physical claims.
